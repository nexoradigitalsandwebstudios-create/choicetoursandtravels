# Image credits

Every photo on the site, where it came from and its licence. Keep this file in step with `content/images.ts` (the /credits page on the site is generated from that file automatically).

Rules we follow:

- Only sources that allow commercial use: Wikimedia Commons, Unsplash (and Pexels, Pixabay or Kerala Tourism if added later). Never Google Images.
- CC BY and CC BY-SA licences require credit to the author, a link to the licence and a note of changes. That is what the /credits page shows, linked from every page footer.
- Images are downloaded, optimised and served from `/public/images/`. Nothing is hotlinked.
- Changes made to every photo: resized, compressed to JPEG, and shown with a light CSS colour grade. Cropped photos are noted.
